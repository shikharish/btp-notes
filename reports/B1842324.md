# B1842324 — Expected behavior

## Finding
The reported behavior is reproduced: `_([1]).union([2])` returns a wrapper containing `[1,2]`, not an array. In Lo-Dash **1.2.1**, this is documented chaining behavior, not an incorrect union result. Use `_.union([1], [2])` or `_([1]).union([2]).value()` to obtain the array.

The report's expectation quotes the array-return contract of static `_.union` but its expression uses the wrapper API. The original report supplied no solution hints beyond this expression.

## Responsible source and historical expectation
References below distinguish original source `repo/lodash.js` from its checked-in executed distribution `repo/dist/lodash.js`, both at the pinned SHA.

1. `repo/lodash.js:223-224` explicitly says `_` creates an object wrapping a value to enable chaining. `repo/lodash.js:233-242` lists chainable wrapper functions, explicitly including **union**. `repo/lodash.js:244-251` separately lists nonchainable functions, including `contains` and `value`.
2. `lodash` at `repo/lodash.js:282-287` routes `_([1])` to `new lodashWrapper(value)`; `lodashWrapper` at `repo/lodash.js:835-839` stores `this.__wrapped__ = value` and shares the lodash prototype. The harness observes the original input identity in this field.
3. `repo/lodash.js:5344` assigns `union` before `repo/lodash.js:5366` calls `mixin(lodash)`, registering it as chainable.
4. `mixin` at `repo/lodash.js:4856-4871` installs anonymous prototype methods. The installed function prepends `this.__wrapped__` to its supplied arguments, so the reported call invokes `union([1], [2])`. It applies the underlying function, then returns `new lodashWrapper(result)` unless the result is the original wrapped object. The observed result is a distinct wrapper containing a new array, matching this branch. This branch trace is static source analysis corroborated by identities and outputs, not an instrumented execution trace.
5. `union` at `repo/lodash.js:3999-4004` computes union using concatenation and `uniq`; its documented static return contract (`repo/lodash.js:3992-3993`) is an array of unique values. This is honored by the static control and by the wrapped payload.
6. `repo/lodash.js:5277-5283` documents extraction; `wrapperValueOf` at `repo/lodash.js:5289-5291` returns `this.__wrapped__`; `repo/lodash.js:5468-5469` installs `value` and `valueOf`.

Thus input → wrapper dispatch → static union yielding `[1,2]` → deliberate rewrapping → observed non-array object. The historical documentation directly supports this distinction; no behavior-changing patch is needed.
