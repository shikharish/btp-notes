## Causal chain
Source modules below explain the shipped Node bundle actually loaded: `repo/package.json:25-26` distinguishes `main` (`repo/moment.js`) from `jsnext:main` (`repo/src/moment.js`); `experiments/pipeline.js:4` explicitly requires the former by default. Bundle counterparts are mapped in the table below.

1. **OBSERVED:** subtracting 44 calendar days gives Feb 17 from April 2 (UTC trace). Calendar-day subtraction uses `addSubtract` at `repo/src/lib/moment/add-subtract.js:27-50`. `fromNow()` calls `from(createLocal())`: `repo/src/lib/moment/from.js:5-17`.
2. **STATIC + OBSERVED:** `from()` requests `createDuration({to:this, from:time})`. The object-input branch in `repo/src/lib/duration/create.js:63-71` calls `momentsDifference` (`repo/src/lib/duration/create.js:106-122`), which uses `positiveMomentsDifference` (`repo/src/lib/duration/create.js:92-104`) to compute whole calendar months then remaining milliseconds. Chronological Feb 17 -> April 2 becomes one calendar month (to March 17) plus 16 days; reversed result has `_months=-1`, `_milliseconds=-1382400000`. Earliest representation divergence from elapsed days occurs here, before humanization.
3. **STATIC + OBSERVED:** `relativeTime`, called by `humanize`, takes absolute duration and rounds conversions (`repo/src/lib/duration/humanize.js:18-43`; caller `repo/src/lib/duration/humanize.js:72-85`). `as('M')` (`repo/src/lib/duration/as.js:15-18`) retains that one month but converts residual 16 days using `daysToMonths` (`repo/src/lib/duration/bubble.js:52-56`), the 400-year average. Result `1 + 16*4800/146097 = 1.5256781453417934`; default `Math.round` (`repo/src/lib/duration/humanize.js:3`) -> 2. Even converted days become 46, not actual elapsed 44 (`as`, `repo/src/lib/duration/as.js:21-24`, using `monthsToDays`, `repo/src/lib/duration/bubble.js:58-61`).
4. **OBSERVED:** branch chooses `MM`, number 2 (`evidence/trace.txt:2-4`). **STATIC:** `relativeTime` selects `MM` (`repo/src/lib/duration/humanize.js:35-36`); locale `defaultRelativeTime`, `relativeTime` and `pastFuture` supply and substitute `%d months` and `%s ago` (`repo/src/lib/locale/relative.js:1-30`). **OBSERVED:** returned string is `2 months ago`.
