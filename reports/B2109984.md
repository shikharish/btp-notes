## Causal sequence
1. **OBSERVED** Original `moment().day('Monday').week('50')` at frozen clock creates Dec 9, 2019. `2019` in input string is unused. `evidence/node-baseline.log`, `evidence/browser.log`.
2. **STATIC + OBSERVED** `add(1,'week')` creates a seven-day duration (`Duration`, `repo/src/lib/duration/constructor.js:26-27`), then `addSubtract` advances native Date's day field (`repo/src/lib/moment/add-subtract.js:27-51`, calling `set` at `repo/src/lib/moment/get-set.js:25-34`; distributed `addSubtract` at `repo/moment.js:3150-3174`). Browser debugger pauses show duration._days=7, days=7, isAdding=1, native Dec 23 before and Dec 30 after. `evidence/debugger.log`. Independent offset observer records delta 604800000 ms at this boundary.
3. **STATIC + OBSERVED** `weekOfYear` intentionally wraps week beyond current year's count and sets resYear to year+1 (`repo/src/lib/units/week-calendar-utils.js:39-59`). On Dec 30, getters return week=1, isoWeek=1, isoWeekYear=2020 while calendar year stays 2019. Debugger and browser logs observe these states. Locale week and ISO week happen to agree here; they are distinct APIs, not interchangeable generally.
4. **STATIC** `YYYY` maps to calendar `year` (`repo/src/lib/units/year.js:22`), `WW` to `isoWeek` (`repo/src/lib/units/week.js:13`). `makeFormatFunction` independently concatenates tokens (`repo/src/lib/format/format.js:45-63`). Earliest divergence from reporter expectation is selecting the calendar-year token for a week-year identifier, not date addition.
5. **OBSERVED** Consumer `console.log` prints formatted calendar date Dec 30 and mixed label `2019-01` (`input/issue.md:28-29`); the native Date is observed separately by the diagnostic harness. It is not a serialization/parsing round trip. Historical tests explicitly support December dates belonging to the next ISO week-year (`repo/src/test/moment/format.js:290-321`, test `iso week year formats`).

## Controls and intervention
One full 53-addition browser baseline, two formatting interventions, and one restoration; each exits 0. Node independently reproduces all baseline rows. Changing only `YYYY-WW` to `GGGG-WW` changes the boundary label to `2020-01`; every date and week-number column is identical across all iterations. `gggg-ww` is a locale-coherent alternative and yields the same labels for these particular dates. Dec 23 and Jan 6 are unchanged negative controls. Restoration compares every console row exactly to baseline. No library changes or suppressed validation; repository remains clean. This is a tested caller-format correction, not a library repair.

Historical tests in `repo/src/test/moment/week_year.js`, `repo/src/test/moment/weeks.js`, and `repo/src/test/moment/format.js` pass 1,425 assertions using original bodies, real Moment and QUnit 2.7.1 (`evidence/historical-tests.log`).
