# B2109889 — verified end to end

## Verdict and oracle
The report's exact observable behavior reproduces against the unmodified Moment 2.24.0 distributed Node entry point: after selecting `en`, `updateLocale('dude', {})` registers and selects a locale but `moment.locale()` returns JavaScript `undefined`, without a warning or exception; exit is 0. This is an identity failure, not evidence that date formatting always fails. The report expects either leaving `en` in place or defining `dude`, with a warning. Its proposed policies are alternatives, not established existing behavior.

Environment: 2.24.0 tag peeled commit `96d0d6791ab495859d09a868803d31a55c917de1`; Node v26.12.0, npm 11.20.0; no dependencies installed or substituted, using tracked `repo/moment.js` (`repo/package.json:25`, `main`). The original modules under `repo/src/` explain the implementation; the baseline and intervention runners explicitly require the distributed bundle (`experiments/baseline.js:2`, `experiments/assertions.js:3`), not those modules. Reporter runtime is unspecified; this is not the reporter's verified environment. `evidence/baseline.txt` records version, commands, results and exit status.

## Causal sequence
1. **OBSERVED** The `dude` load misses; trace shows default `baseConfig` has no `abbr`. **STATIC** `loadLocale` tries the locale module and suppresses its failure (`repo/src/lib/locale/locales.js:48-60`); update falls back to `baseConfig` rather than rejecting the name (`repo/src/lib/locale/locales.js:143-150`). `baseConfig` has no abbreviation (`repo/src/lib/locale/base-config.js:26-44`).
2. **OBSERVED** Merging `{}` produces config without `abbr`, and the constructed locale has no `_abbr` (`evidence/trace.txt`). **STATIC** update never supplies a name to the config (`repo/src/lib/locale/locales.js:151-154`); `mergeConfigs` copies the parent and child (`repo/src/lib/locale/set.js:25-49`), and `set` maps non-function config values to underscore-prefixed fields (`repo/src/lib/locale/set.js:6-16`). `Locale` calls `this.set(config)` (`repo/src/lib/locale/constructor.js:1-5`); the prototype binding is at `repo/src/lib/locale/prototype.js:21`. This is the earliest responsible divergence: the missing-name creation path does not initialize locale identity.
3. **OBSERVED** The object is registered under `dude`, then becomes the global locale, and its missing `_abbr` is returned by the public getter. **STATIC** registration and global selection occur at `repo/src/lib/locale/locales.js:153-157`; `getSetGlobalLocale` assigns the found object and reads its `_abbr` at `repo/src/lib/locale/locales.js:66-89`, with lookup in `getLocale` at `repo/src/lib/locale/locales.js:172-193`. The expected warning is not emitted because the freshly registered object is found. A new instance's locale getter likewise returns undefined (`repo/src/lib/moment/locale.js:7-12`); instances still format using inherited defaults.

## Controls and intervention
Updating existing `en` inherits its configuration's `abbr`; updating dynamically loadable `fr` also yields `fr`. Defining `dude` returns `dude`, consistent with `defineLocale` explicitly assigning `config.abbr = name` (`repo/src/lib/locale/locales.js:91-94`). Controls run in independent processes. See `evidence/baseline.txt`, `evidence/trace.txt`, and `evidence/intervention.txt`.

A temporary one-line diagnostic intervention in the actual distributed `updateLocale` sets the merged config's `abbr` to the requested name only when load missed (`experiments/intervention.py:6-7`, inserted between the original `repo/moment.js:1948-1949`). The unknown case changes from undefined to `dude` in both global and instance getters; registration, global-object identity and a custom `LL` format (`CUSTOM 2019`) remain operational. Existing `en`, loadable `fr`, and `defineLocale` controls pass unchanged. Restoring the original bundle returns the exact undefined symptom and the same controls pass; SHA-256 verification and clean git status confirm restoration. See `experiments/intervention.py` and `evidence/intervention.txt`.

The intervention neither warns nor tests all cases such as explicit `abbr`, parent locales, and unupdate semantics; it is diagnostic, not a complete remediation. No full suite or other runtimes were tested. The tracing instrumentation temporarily changes the bundle and is removed before intervention; its generated `TRACE` logging statements are defined in `experiments/trace.py:6-9`, applied at `experiments/trace.py:10-14`, and restored at `experiments/trace.py:19-20`. They are not original Moment source; the bundle references below use restored, uninstrumented line numbers. No other cases, prior answers, fix history, or online explanations were accessed.
