## Causal sequence
1. **STATIC + OBSERVED:** `mount(...,{props:{testData:new AppTest(...)}})` reaches test-utils `createInstance` (`experiments/node_modules/@vue/test-utils/dist/vue-test-utils.cjs.js:8384-8385`); `experiments/node_modules/@vue/test-utils/dist/vue-test-utils.cjs.js:8193-8202` stores props in `Vue.reactive({})`, then `Parent.render` spreads them into the child (`experiments/node_modules/@vue/test-utils/dist/vue-test-utils.cjs.js:8217-8218`). Raw input is not a proxy before mount, but the SFC observes both class and Map as proxies (`evidence/trace-baseline.log`). Vue's `initProps` makes stateful, non-SSR component props shallow reactive (`experiments/node_modules/@vue/runtime-core/dist/runtime-core.cjs.js:4109-4110`); the nested proxy originated in test-utils, not a universal rule that every Vue prop deep-wraps its input.
2. **OBSERVED:** `props.testData.clone()` (`experiments/components/AppTestComponent.vue:8`) executes `AppTest.clone` (`experiments/models/AppTest.ts:6`) on that proxied receiver. Its Map has size 2 and `[object Map]` tag. Native `util.types.isMap` returns false for it (`evidence/trace-baseline.log`).
3. **STATIC + OBSERVED:** lodash loads `util.types` and selects `nodeIsMap` (`repo/lodash.js:451-468`, `repo/lodash.js:11861`). `cloneDeep` calls `baseClone` (`repo/lodash.js:11155-11156`), which tags the Map (`repo/lodash.js:2684-2685`), calls `initCloneByTag` (`repo/lodash.js:2701`), and records the new empty Map in its stack (`repo/lodash.js:2710`). `initCloneByTag` allocates it with `new Ctor` (`repo/lodash.js:6267-6268`).
4. **OBSERVED + STATIC:** `baseClone` population is guarded by the separate `isMap(value)` predicate (`repo/lodash.js:2716-2719`). False means no `forEach` and no `result.set`; Map entries are not enumerable object properties and the ordinary property pass cannot copy them (`repo/lodash.js:2722-2735`). Instrumented baseline logs Map detection but no population entries for mounted inputs; raw direct control logs both keys (`evidence/trace-baseline.log`).
5. **OBSERVED:** SFC exposes a distinct empty Map, original remains size 2. Assertion on clone keys fails (`experiments/baseline.spec.ts:13-18`). Both initially raw and explicitly reactive mount inputs do this. Browser has tag-based detection (`repo/lodash.js:11861`, `repo/lodash.js:3385-3386`; Node util unavailable), so the same mounted proxy is recognized and both entries survive (`evidence/browser.log`).

No assumed link is needed to explain reconstructed Node failure. Original reporter environment identity remains unknown.

- Unmodified npm lodash baseline runs compiled Vue SFC through actual Vitest/jsdom/test-utils, not a copied algorithm.
- Negative controls: direct raw class clone; plain Vue createApp with raw root props in jsdom; markRaw class through test-utils. All retain entries. The toRaw raw-input control is redundant, not evidence that toRaw removes nested proxies generally.
- Diagnostic alias (`experiments/vite.config.ts:3`, `resolve.alias`) uses the generated `experiments/lodash-trace.cjs` copy of the historical full implementation with only two logging additions (`experiments/lodash-trace.cjs:2686`, `experiments/lodash-trace.cjs:2719`; `evidence/trace-only.diff`), not a substitute implementation.
- Narrow intervention (`experiments/run-matrix.sh:14`) changes only `isMap` selection to `nodeIsMap(value) || baseIsMap(value)`. Same inputs now traverse `forEach`, log name1/name2, preserve keys, and clone values into distinct objects (`evidence/intervention.log`). It does not skip clone or fake success.
- Restore original predicate, retain logging: empty Maps recur (`evidence/restoration.log`). Source repository and npm baseline remain untouched. Restored trace copy is retained.
- Real headless Chromium loads the same SFC through loopback Vite, mounts it with test-utils, checks keys and first value name, and also creates a plain Vue app. Both retain entries.

## How I reproduced and debugged it

1. `bash experiments/run-matrix.sh` exercised the actual Vue SFC through Vitest, jsdom and test-utils, then through Vite and Playwright/Chromium. The Node baseline mounted successfully but failed two clone-entry assertions; direct/raw controls passed.
2. Followed test-utils `mount/createInstance` and Vue `reactive` handling into the SFC's `AppTest.clone`, then Lodash `cloneDeep/baseClone/initCloneByTag`. Comparing native Map detection with the Map tag localized allocation versus population disagreement.
3. The `TRACE=1` alias selected a separate instrumented Lodash copy. Logged proxy flags, native predicate results and entry-copy activity showed the proxied two-entry Map being allocated but not populated. This was runtime logging and browser automation, not GDB or a browser-breakpoint session.
4. Changing only the diagnostic Map predicate restored all six assertions; restoring it reproduced the two failures. The real browser retained both entries. `evidence/matrix.log`, `evidence/trace-baseline.log`, `evidence/intervention.log`, `evidence/restoration.log` and `evidence/browser.log` preserve the comparisons. The cause is demonstrated; the historical Proxy-support obligation remains unresolved.

Full generic Proxy support and tag spoofing semantics are not validated by the predicate intervention; it is diagnosis, not a production repair. No full upstream regression run, no clone-deep replacement comparison, and no original browser artifact. Browser acquisition and dependency installation succeeded; no hard execution blocker.

Native Maps are documented/tested clone inputs, but the failing object is a Vue Proxy. The historical tests do not settle whether that wrapper must be supported. Consequently reproduction and mechanism are confirmed, not a breach of a documented Proxy guarantee. Do not equate the status label with a confirmed-defect verdict.
